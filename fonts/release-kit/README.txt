KMRP Original HD fonts, version 1.600
=====================================

KOTOR's own fonts in high resolution: 11 OpenType fonts, redrawn from scratch as
straight lines, sharp corners and arcs. The letter widths, spacing and baseline match
the game's own fonts, so text set in them lines up as it does in KOTOR.

Made by RaymanGT for KMRP, the KOTOR Modern Restoration Patch:
https://github.com/RayesDiyab/KMRP-KOTOR-Modern-Restoration-Patch
The fonts' own home, with how they were made:
https://github.com/RayesDiyab/KOTOR-KMRP-Font-Converter

What is in this download
------------------------

KMRP-OriginalHD.ttc   all 11 fonts in one file (the easiest to install)
otf\                  the same 11 fonts as separate .otf files
OFL.txt               the license

Install the .ttc OR the .otf files, not both, or every font shows up twice in your
font list.


How to install (Windows)
------------------------

Right-click KMRP-OriginalHD.ttc and choose "Install" (or "Install for all users").
To install only some fonts, do the same with the files you want in the otf folder.
On macOS, double-click a file and choose "Install Font". On Linux, copy the files to
~/.local/share/fonts and run fc-cache.

The fonts appear in your font list as "KMRP Original HD ..." (for example
"KMRP Original HD Dialogue").


Which font is which
-------------------

The game keeps the same letters under several names, so 11 fonts cover all 17 of
its text fonts.

Font            Game font names                          Used in the game for
--------------  ---------------------------------------  ---------------------------------
Menu            dialogfont16x16, dialogfont16x16b        screen titles, menu buttons
Menu Small      dialogfont10x10, 10x10a, 16x16a          option lists, small labels
Menu Small B    dialogfont10x10b                         tabs, small bold labels
Menu Medium     dialogfont12x16                          save and load lists
Menu Large      dialogfont32x32                          the largest headings
Dialogue        fnt_d16x16, fnt_d10x10b                  conversations, subtitles
Descriptions    fnt_d16x16b                              reply choices, descriptions
Light           fnt_d16x16a, fnt_creditsa,               the journal, longer reading
                fnt_dialog16x16
Console         fnt_console                              the HUD's numbers
Credits         fnt_credits                              job titles in the end credits
Credits Bold    fnt_creditsb                             names in the end credits


Good to know
------------

- Characters: the Western European set (Windows-1252), the same as the game:
  English, French, German, Italian, Spanish and similar. Console has digits,
  letters and punctuation only.
- Kerning: the fonts carry letter-pair kerning for programs that use it (browsers,
  Word, design tools). The game itself does not kern.
- Console is monospaced. In the game it is drawn with a black outline, which is not
  part of the font.
- These are font files for your computer and your own projects. They do not change
  the game by themselves. To get HD text in KOTOR, install KMRP and choose
  "HD Font" on its Text Size and Font page.
