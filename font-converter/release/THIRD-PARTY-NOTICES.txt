KMRP Font Converter: what is in it, and whose
=============================================

Everything in the program is the KMRP project's own, made by RaymanGT, except where this
file says otherwise.

Fonts carried in the program
----------------------------

KMRP Original HD Menu and KMRP Original HD Descriptions, as TrueType, set the window's
text. They are KMRP's own fonts, Copyright (c) 2026, RaymanGT, under the SIL Open Font
License 1.1 (OFL.txt, beside this file). No Reserved Font Name.
https://github.com/RayesDiyab/KOTOR-KMRP-Font-Converter/tree/master/fonts

The pictures of example text on the tiles are drawn in the same KMRP Original HD fonts.

Pictures
--------

The KMRP and KOTOR logos, and the program's icon (the same crest above the word FONT): the
crest is KMRP's own artwork (its sigil); the letters are drawn with the Georgia typeface
(a picture of the letters, not the font file). The settings gear is the KMRP installer's
own.

Names
-----

"Star Wars", "Knights of the Old Republic", "KOTOR", "BioWare" and "LucasArts", and
the game's character and place names in the example lines, are trademarks or names of
their owners, used only to name the game and its text. The KMRP Font Converter is a fan
project and is not affiliated with them.

Fonts the window falls back on
------------------------------

The window's text is in the two KMRP fonts above. For the few signs they lack, and for the
output folder's path, it falls back on the fonts egui (the window's toolkit) carries, compiled
into the program by the crate epaint_default_fonts: Ubuntu Light (Ubuntu Font Licence 1.0),
Hack (MIT), Noto Emoji (SIL Open Font License 1.1) and emoji-icon-font (MIT).

Rust crates
-----------

Since 2026-11-09 the converter is a Rust program (until then C# on .NET Framework, which
read font files through Windows' DirectWrite and carried no one else's code). It is built
from these crates, each under the licence named beside it, all of them compatible with the
GPL-3.0-or-later the converter is released under. The list is every crate compiled into the
program for Windows, macOS or Linux (some are only in one of them), from

  cargo tree -e normal --target all --prefix none -f "{p}|{l}"

in the font-converter folder (2026-11-09, 286 crates). The chief ones: egui and eframe
(the window), wgpu and glow (drawing it), skrifa and read-fonts (reading fonts and their hinting), wuff (WOFF2), image
(the PNG pictures), rfd (the file pickers), miniz_oxide (WOFF's zlib), dirs, winreg.

Each crate's licence text is in its source, on crates.io. The MIT licence asks that its
notice travel with the program: "Permission is hereby granted, free of charge, to any person
obtaining a copy of this software and associated documentation files (the "Software"), to
deal in the Software without restriction ... The above copyright notice and this permission
notice shall be included in all copies or substantial portions of the Software. THE SOFTWARE
IS PROVIDED "AS IS", WITHOUT WARRANTY OF ANY KIND." The Apache License 2.0 is at
https://www.apache.org/licenses/LICENSE-2.0.
